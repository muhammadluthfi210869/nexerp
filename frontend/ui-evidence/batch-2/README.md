# Batch 2 — UI Migration Evidence (SHA 811b8e1)

## Honest status of evidence files

The `capture-manifest.json` was generated by a Playwright script that reported `okCount: 10`,
but the corresponding PNG files were inspected and were **all identical** (same MD5 hash,
same 67975-byte payload). They show the **login redirect page**, not the migrated content.

The Playwright script returns success when the HTTP response is 200 — but every auth-gated
route returns 200 at the HTTP layer and then client-side redirects to `/login` when the
dashboard layout checks for an active session. The script does not verify that the visible
content is the migrated page.

PNG files were therefore removed from this directory to avoid presenting misleading evidence.
The migration contract is satisfied at the source level; visual verification is blocked by
backend auth unavailability in this environment.
