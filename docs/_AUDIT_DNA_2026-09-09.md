## 2. ANALISIS VISUAL_DNA.md (283 baris)

### 2.1 Struktur
VISUAL_DNA.md punya 6 bagian utama:

1. **Scope Definition** — apa IN/OUT dari DNA (Section 0 di roadmap).
2. **Anatomi Baku 5 Layer** — vertical rhythm halaman.
3. **Spesifikasi per Layer** — kode TSX copy-paste ready.
4. **Anti-Patterns** — apa yang DILARANG.
5. **Implicit tokens** — ukuran font, radius, warna hard-coded.

### 2.2 Kelebihan VISUAL_DNA.md ✅

1. **Sangat spesifik** — setiap layer punya className Tailwind lengkap, tidak abstrak.
2. **Copy-paste-ready TSX** — developer tinggal copy snippet, tidak interpretasi.
3. **Definitive anti-patterns** — 5 larangan eksplisit (no giant card wrapper, no traffic-light buttons, no random primary button di tabel, no mixed columns, no hardcoded values di luar skala).
4. **Skala eksplisit**:
   - Judul Halaman: `text-[32px] leading-[40px] font-bold`
   - KPI Value: `text-[24px] leading-[32px] font-bold`
   - Data Tabel: `text-[12px] font-semibold / font-medium`
   - Header Tabel & Badge: `text-[10px] / text-[11px] uppercase font-bold`
   - Radius: `rounded-xl` (10–12px)
5. **SSOT klaim eksplisit**: "Dilarang menciptakan abstraksi wrapper baru atau mengikuti aturan lama yang bertentangan dengan file master ini."

### 2.3 Kritik VISUAL_DNA.md ❌

1. **Token system TIDAK enforced** — setiap className di-hardcode (`text-[24px]`, `bg-slate-50`, `rounded-xl`). Tidak ada `tailwind.config.ts` extension untuk `text-h1: 32px`, `color-dna-primary: #...`. Drift dijamin.

2. **Dua DNA system ambigu** — VISUAL_DNA.md adalah Operational DNA. Dashboard DNA ada di `old_erp/ACUAN_DASHBOARD/`. Roadmap bilang "BUKAN conflict", tapi:
   - Operational pakai `rounded-xl`
   - Dashboard pakai `rounded-[24px]` (Aureon Matrix)
   - Operational pakai `border-slate-200`
   - Dashboard pakai `border-[var(--border-color)]`
   - Operational pakai font default Tailwind
   - Dashboard pakai Inter font eksplisit

3. **Motion spec HILANG** — VISUAL_DNA sebutkan "bouncy/animasi" overdue (legacy ERP spec) tapi DNA tidak punya animasi/motion token. AP Aging color spec di luar DNA.

4. **Tidak ada dark mode spec** — hanya light mode didokumentasikan. Padahal `tailwind.config.ts` bisa extend dark: variants.

5. **Tidak ada responsive spec** — kapan mobile, kapan tablet, kapan desktop? Hanya desktop layout dijelaskan.

6. **Tidak ada accessibility (a11y) spec** — contrast ratio, focus state, ARIA, screen reader behavior.

7. **Tidak ada icon system** — pakai Lucide sudah jadi standar de facto, tapi tidak ada icon registry/size spec.

8. **Empty state & loading state spec minim** — hanya `DnaErrorState` dan `DnaLoadingSkeleton` ada sebagai component, tidak ada design rule.

9. **Tab container vs Bordered Tab Nav** — VISUAL_DNA Section "Layer 03" jelaskan: "bg-white border border-slate-200 rounded-xl p-1 shadow-2xs h-[46px]". Tapi di golden-reference line 580–586, `DnaPageHeader.tabs` dipakai untuk tab navigation yang NOT a separate bordered container — tabs jadi SATU dengan header. Inkonsistensi.

10. **Scope In/Out table ambigu** — VISUAL_DNA exclude "dna-visual reference pages" tapi golden-reference IS the canonical implementation. Mana yang jadi acuan aktual?

## 3. ANALISIS GOLDEN REFERENCE PAGE (`page.tsx`)

### 3.1 Profil
- **Path**: `frontend/src/app/(dashboard)/dna-visual/golden-reference/page.tsx`
- **Size**: ~1.400 baris (saya baca sampai line 1018+)
- **Function**: Specimen halaman operasional kanonikal — berisi 1 halaman lengkap dengan Header → KPI Grid → Tabs → Toolbar → Table → Floating Detail Modal → Create Modal → Edit Modal → Confirm Dialog.

### 3.2 Yang Digunakan dari DNA
```
DnaPageHeader      ← Layer 01 (header dengan tabs)
DnaKpiGrid         ← Layer 02 (4 KPI cards)
DnaDataTableCard   ← Layer 04+05 wrapper (toolbar + children)
DnaCell.Code       ← Cell: WO code (clickable)
DnaCell.Text       ← Cell: text primary/secondary
DnaCell.Badge      ← Cell: status badge
DnaCell.Progress   ← Cell: progress bar
DnaCell.Avatar     ← Cell: PIC with initial avatar
DnaCell.Number     ← Cell: number formatted id-ID
DnaCell.Currency   ← Cell: Rp formatted id-ID
```

### 3.3 Yang TIDAK Digunakan (Padahal VISUAL_DNA Prescribe)
1. **`DnaTable` primitives** (`DnaTable`, `DnaTableHead`, `DnaTableRow`, `DnaTh`, `DnaTableBody`, `DnaTd`, `DnaTdNumber`, `DnaTdCode`) — Golden reference pakai RAW HTML `<table>` (line 625–668). Inkonsistensi internal.
2. **`DnaPagination`** — dipakai di prop `paginationProps` tapi dengan `currentPage: 1, totalPages: 1, onPageChange: () => {}` (no-op). Pagination tidak benar-benar berfungsi.
3. **`DnaToolbar`** sebagai standalone — hanya via `DnaTableToolbar` di dalam `DnaDataTableCard`.
4. **Confirmation Dialog** — Golden reference pakai RAW HTML custom (`{confirmDialog.isOpen && ...}`), bukan `DnaConfirmDialog`.
5. **Create/Edit Modal** — RAW HTML, bukan `DnaCrudModal`.
6. **Toast** — RAW HTML state, bukan `useDnaToast` hook.
7. **Layer 03 (Bordered Tab Nav Container)** — Tidak ada di golden-reference! `DnaPageHeader` punya inline tabs tapi tidak dalam bordered container terpisah seperti spec VISUAL_DNA Layer 03.

### 3.4 Kritik Golden Reference ❌

1. **Pelanggar terhadap spec-nya sendiri**: VISUAL_DNA Layer 03 prescribe bordered tab container (`h-[46px]`, `p-1`). Golden reference pakai tab dalam header (`h-8 px-3.5` di `DnaPageHeader`). Deviasi 100% dari Layer 03 spec.

2. **CSS variable deviation**:
   - VISUAL_DNA: `border-slate-200` (no opacity)
   - `DnaDataTableCard`: `border-slate-200/90` (90% opacity)
   - `DnaPageHeader`: `border-slate-200/90`
   - Visual akan lebih tipis dari spec.

3. **Padding deviation**:
   - VISUAL_DNA Layer 02: `border rounded-xl p-3.5` (p-3.5 = 14px)
   - `DnaKpiCard`: `p-5` (20px). Lebih besar dari spec.

4. **KPI card height deviation**:
   - VISUAL_DNA: `h-[104px]`
   - `DnaKpiCard`: `h-[116px]`. Lebih tinggi 12px.

5. **KPI font size deviation**:
   - VISUAL_DNA: `text-[24px] leading-[32px] font-bold`
   - `DnaKpiCard`: `text-[22px] font-black tracking-tight leading-none`. Lebih kecil dari spec (22 vs 24) tapi lebih bold.

6. **Toolbar padding deviation**:
   - VISUAL_DNA Layer 04: `p-3` (12px)
   - `DnaTableToolbar`: `p-4` (16px). Lebih besar.

7. **Page header font deviation**:
   - VISUAL_DNA Layer 01: `text-[32px] leading-[40px] font-bold`
   - `DnaPageHeader`: `text-[26px] md:text-[28px] font-black uppercase`. Lebih kecil + berbeda weight (black vs bold).

8. **Golden reference bukan "Single Source of Truth"** — kalau developer copy-paste dari golden-reference tanpa membaca VISUAL_DNA, akan menghasilkan halaman yang berbeda dari yang VISUAL_DNA inginkan.

9. **Mock data hard-coded 10 WorkOrder entries** (line 87-278) — golden-reference bukan empty state, tapi demo state. Audit perlu klarifikasi apakah ini "reference untuk production code" atau "demo saja".

10. **Floating detail window menggunakan RAW HTML** (line 672-794) — tidak reuse `DnaModal` atau `DnaSheet`. Pelanggaran internal.

11. **No responsive spec tested** — semua className `flex flex-col md:flex-row` di-handle, tapi visual diff pada mobile belum ada visual regression test.

12. **Custom CSS classes referenced** (`custom-scrollbar`, `animate-in`, `fade-in`, `slide-in-from-top-3`, `zoom-in-95`) — apakah dari `tailwind.config.ts` atau dari `globals.css`? Audit diperlukan.

7. **Tidak ada filter chips** setelah dipilih — kalau filter aktif, tidak ada visual ringkasan di atas tabel.

9. **`startDate` & `endDate` default ke empty string** — kalau mode CUSTOM tapi tanggal kosong, filter tidak ter-apply (silent fail).

### 4.5 `DnaCell.tsx` (320 baris, 9 sub-components)

**Sub-components**:
1. `DnaCellCode` — clickable code (WO, PO, SKU)
2. `DnaCellText` — primary + secondary text
3. `DnaCellBadge` — auto-styled by status keyword (BUG untuk Indonesia!)
4. `DnaCellProgress` — bar + percent
5. `DnaCellAvatar` — initial + name + subtext
6. `DnaCellNumber` — formatted id-ID, right-aligned, tabular-nums

8. `DnaCellDate` — string date display
9. `DnaCellActions` — View/Edit/Delete buttons

**Kritik Khusus `DnaCell.Badge`**:

`getStatusBadgeStyle(status)` function punya logic:
```ts
if (normalized.includes("finish") || "selesai" || "approved" || "lunas" || "pkp" || "active") → emerald
if (normalized.includes("mix") || "progress" || "proses" || "bbk" || "info") → sky
if (normalized.includes("wait") || "tunggu" || "material" || "hold" || "kemasan") → amber
if (normalized.includes("pending") || "review" || "draft") → orange
if (normalized.includes("cancel") || "reject" || "batal" || "gagal" || "non") → rose
else → slate (default)
```

**MASALAH KRITIS**: Function ini **subset-only untuk keyword English**. Indonesian keywords yang umum di legacy ERP:
- "Disetujui" → bukan substring dari "approved" (beda kata!) → jatuh ke default slate
- "Selesai" → ✅ match
- "Berjalan" → tidak ada di list → slate
- "Revisi" → tidak ada → slate
- "Tertunda" → tidak ada → slate
- "Belum Dibayar" → tidak ada → slate
- "Sudah Dibayar" → tidak ada → slate
- "Menunggu" → bukan substring dari "wait" atau "tunggu" → slate

→ **Visual badge untuk 70% status Indonesia akan jadi slate default.**

**Kritik Lain `DnaCell.tsx`** ❌:
1. **`DnaCellCode` subtitle** prop tidak jelas kapan dipakai.
2. **`DnaCellText` default `maxWidth: 280px`** — hard-coded.
3. **`DnaCellBadge` `label` vs `status`** prop redundancy. Default `status || label || ""`.
4. **`DnaCellProgress` color default "bg-blue-600"** tapi golden-reference pakai "bg-emerald-500", "bg-sky-500", "bg-amber-500" — color tidak konsisten.
5. **`DnaCellAvatar` `max-w-[180px]` truncate** — bisa hide nama panjang PIC.
6. **`DnaCellActions` icon hover color** (blue/emerald/rose) tidak match VISUAL_DNA anti-pattern #2 yang melarang "efek lampu lalu lintas".
7. **`DnaCellActions` tidak ada prop `onPrint` atau `onExport`** — padahal legacy ERP butuh export Excel per row.
