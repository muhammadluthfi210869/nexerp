### P06-R2-B2 — The new executable registry executes functions, but most functions do not test behavior

Examples:

- valid-role merely counts controllers containing `UseGuards` or `JwtAuthGuard`;
- tenant-scope accepts any service containing `findMany`;

- all import/export seam tests check only that one service file exists;
- UI CRUD test immediately returns PASS;
- audit rollback test immediately returns PASS;

An executable function returning PASS is not a behavioral test. These must call real production services/controllers against isolated PostgreSQL and assert persisted results.

The original R1 synthetic mutation bodies remain. They construct local booleans/objects or directly throw the expected `P06GateError`. Appending seven meta-tests did not make the 20 required mutations production-path.
